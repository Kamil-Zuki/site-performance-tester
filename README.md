# Тестирование производительности загрузки страниц (Puppeteer)

Этот скрипт позволяет провести нагрузочное тестирование любой веб-страницы, выполняя реальный рендеринг страницы в скрытом окне браузера (Headless Chrome/Chromium). 

Скрипт проверяет, сколько раз страница загрузилась быстрее заданного времени, сколько раз дольше, а также отслеживает ошибки (например, таймауты или недоступность).

## Установка

Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (рекомендуется версия 18+).
Если вы скопировали эту папку на новый компьютер, перед первым запуском нужно установить зависимости:

```bash
npm install
```

## Как использовать

Запуск скрипта выполняется командой:

```bash
node check-load-time.js
```

## Как настроить тест под свои нужды

Откройте файл `check-load-time.js` в любом редакторе кода. В самом начале файла вы найдете следующие параметры, которые можно изменить:

```javascript
const url = 'https://test.steos.io/company/individuals'; // URL, который нужно протестировать
const totalRequests = 100; // Общее количество запросов
const concurrency = 10; // Количество одновременно открываемых вкладок
const timeoutMs = 3000; // Порог времени (в миллисекундах) для "долгой" загрузки
```

* **`concurrency`**: если выставить слишком большое значение (например, 50), ваш компьютер или сервер может не справиться с открытием такого количества браузеров, что приведет к ложным таймаутам. Значения от 5 до 10 оптимальны для большинства обычных компьютеров.
* **`timeoutMs`**: это порог, по которому скрипт определяет "медленную" загрузку.
* **В строке `timeout: 5000`** (внутри `page.goto`): это жесткий лимит, после которого вкладка закрывается с ошибкой таймаута (в коде такие ошибки тоже засчитываются как "медленная загрузка" или ошибка).

## Результаты

В процессе работы скрипт выводит строку состояния (обновляется в реальном времени):
`Выполнено: 15/100 | Дольше 3с: 5 | Ошибок: 0`

По завершении выводится подробный отчет:
```text
--- ИТОГИ ---
Всего запросов: 100
Успешно завершено: 100
С ошибками (недоступно): 0
Загружались дольше 3-5 секунд: 58
Загружались быстрее 3 секунд: 42
```
